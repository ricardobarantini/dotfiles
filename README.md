# Dotfiles

Repositório contendo meus dotfiles personalizados.

## Requisitos

- zsh
- oh-my-zsh
- antigen

## Configurações disponíveis

- Oh My Zsh
- Antigen
- Hyper Terminal com tela Dracula
- Tema Spaceship para Oh My Zsh

## Como instalar

Copiar o conteúdo da pasta `shell` para o diretório `home`.
