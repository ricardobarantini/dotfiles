# Dotfiles

Repositório contendo meus dotfiles personalizados.

## O que contém?

- Antigen
- Hyper Terminal com tela Dracula
- Oh My Zsh
- Tema Spaceship para Oh My Zsh

## Como instalar

`git clone git@github.com:ricardobarantini/dotfiles.git`

`cd dotfiles`

`sudo chmod +x install.sh`

`zsh ./install.sh`
