# Dotfiles

![.dotfiles banner](dotfiles.png)

This is my personal dotfiles to use on Arch with Hyprland.

## Settings available

- bash
- [btop](https://github.com/aristocratos/btop)
- [fastfetch](https://github.com/fastfetch-cli/fastfetch)
- [ghostty](https://github.com/ghostty-org/ghostty)
- git
- [hyprland](https://github.com/hyprwm/Hyprland)
- [mako](https://github.com/emersion/mako)
- [neovim](https://github.com/neovim/neovim) (with [LazyVim](https://github.com/LazyVim/LazyVim))
- [starship](https://github.com/starship/starship)
- [swayosd](https://github.com/ErikReider/SwayOSD)
- [tmux](https://github.com/tmux/tmux)
- [walker](https://github.com/abenz1267/walker) (with [elephant](https://github.com/abenz1267/elephant))
- [waybar](https://github.com/Alexays/Waybar)
- [zed](https://github.com/zed-industries/zed)
- zsh

## Installation

```bash
git clone https://github.com/ricardobarantini/dotfiles.git
cd dotfiles
```

### GNU Stow

This dotfiles can be installed using [GNU Stow](https://www.gnu.org/software/stow/).

`stow -t ~ <app-name>`
